# Cloudflare DNS Management MCP Server 🛠

This is a [Model Context Protocol](https://modelcontextprotocol.io/introduction) server that enables managing DNS records through Cloudflare's API. It supports remote MCP connections and OAuth-based authentication.

## 🔨 Available Tools

Currently available tools:

| **Category** | **Tool** | **Description** |
| ------------ | -------- | --------------- |
| **DNS** | `dns_record_create` | Create a DNS record in a zone |
| **DNS** | `dns_record_update` | Update a DNS record in a zone |
| **DNS** | `dns_record_delete` | Delete a DNS record from a zone |

This MCP server is a work in progress and additional DNS tools may be added in the future.
